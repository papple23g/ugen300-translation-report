  2. 保留備選模型結果，以選型價值決定投入。 Nemotron 的 IFP 短尾曾出現空文字；帶前文拼接的單案候選未過預定條件。它的專屬短尾除錯暫不優先，除非後續需求或可比較證據顯示它能補足主候選缺口；問題不能推論為所有 STT 模型都會發生。短尾對照（原件在研究電腦）
  3. 依語言優先分組擴展語音、翻譯與摘要。 先盤點每種輸入語言、文字輸出及目標語言的既有能力與缺口，再準備資料和受控驗證；不因模型卡、介面語系或其他平台有支援就標成目標設備已通過。
  4. 並行準備會議總結。 先以既有可行 runtime 和人工事實參考篩選短例，將合格候選推進到完整會議、來源追溯與完成時間；沒有可用候選時先處理品質，不把格式正確或摘錄原文當作合格摘要。
  5. 比較設備分工並完成整機驗證。 分別記錄 IFP CPU / IFP NPU / IFP GPU / UGen NPU 的可執行性與實測，最後在實際收音、畫面與資源並行條件下比較 IFP 單機和 IFP + UGen 的增量效益。

各研究軌與關卡

語音辨識

  • P1 先保留中文、英文、混語與遠場基準及固定評分；短尾先檢查 SenseVoice 現有結果，缺口才以少量代表音訊補測。多人重疊與切窗目前只是遠場共同漏字的待查因素，不先當成已證實原因。
  • P2 至 P7 先按語言 / 地區 / 腔調核對模型來源宣稱、授權、目標裝置 runtime、資源與音檔 / 人工參考。SenseVoiceSmall 原始文件明列中文、英文、日文、韓文與粵語；這不證明本專案的量化模型在其他優先語言有品質或可用性結果。模型卡
  • 可執行後先比較同一音訊及參考，記模型 / 前處理 / 視窗 / 硬體 / 分母 / S-D-I / 完整性 / 計時與資源；按語言與書寫特性預先凍結字元或詞的正規化與錯誤率。現有中文 CER ≤15%、英文 WER ≤20%、中英混語 MER ≤20% 是研究門檻；其他語言的指標及門檻須另訂，不把舊門檻直接套用。
  • 有價值的新候選才做小規模目標裝置對照；無相容入口的模型或轉換是高風險可行性研究，先設成本上限、停止條件並取得核准，不列為一般長測。

多語言翻譯

  • 沿用已完成的中英六模型受控文字結果；品質由 LLM 判讀且尚未人工複核，持續輸入測試也不代表自然會議 / 畫面延遲。
  • 以既有英文 / 繁中方向作基準，逐 P 組確認實際需要的來源語言與目標語言，再逐語對盤點可用模型、授權、裝置資源與離線條件。不要把語音識別語言、UI 語系和翻譯輸出語言混為一項。
  • 以同一人工核對來源評估忠實、遺漏、數字、人名、否定、目標語言與完整性；區分乾淨人工逐字稿和 ASR 輸出，並測試持續輸入 / 尾段排空。字幕與譯文的 p95 仍以實際句尾到畫面計算。

  • 已有 Qwen3、Gemma 等有限案例探索，但沒有可直接自動採用的合格改寫摘要。Gemma4 的來源分類嚴格條件曾為 0 / 6，Gemma3 1B 的四個完整摘要有核心錯義；IFP 文字研究由助理逐來源判讀，未經獨立人工裁決，也不是自然會議驗收。這些屬各自固定測試，不推論整個模型家族均不可行。摘要探索（原件在研究電腦） / IFP 文字研究（原件在研究電腦）
  • 先建立中 / 英 / 混語開發與隔離資料，為決議、行動、負責人、日期和必要主題建立人工事實參考與可追溯來源；既有已曝光資料只作開發。先以完整人工逐字稿評估摘要，再獨立評估實際 ASR 錯誤的影響。

  • 停止並排空後封存完整會議快照，記錄 session / generation、段落版本與 SHA；依 tokenizer 預算分塊並保留原始來源。研究門檻是 60 分鐘會議在 600 秒內完成；明示決議 / 行動 / 負責人 / 日期零漏編、零杜撰，其他必要主題以人工參考為分母至少 90%。逾時、截斷及無輸出計入分母。原文未指派者標示身分待確認，未給期限標示未指定。摘要評分條件（原件在研究電腦）
